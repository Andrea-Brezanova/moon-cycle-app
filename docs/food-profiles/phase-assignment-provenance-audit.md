# Food-to-phase assignments: provenance summary and limits

**Documentation only. No phase mapping, catalogue entry or app behaviour was changed.** Machine-readable detail: `phase-assignment-provenance-matrix.json`.

## What this document does and does not say

- It records **when** each of the 142 food-to-phase assignments entered this repository and how it changed, from Git history.
- It does **not** establish where the assignments originally came from. The earliest list pre-dates this repository and its source is not established here.
- It does **not** say the assignments are independently sourced, legally cleared or scientifically validated. **None of those three is true of the current assignments**: no assignment has a documented independent source; no legal review has been done; and no reliable research shows that any food needs to be eaten in a particular phase.
- The featured phase is an editorial suggestion for variety (the app says: "These are suggestions, not rules"), not a nutritional requirement.
- The evidence base is this repository only. Other records exist outside it and are not reproduced here.

## Scientific support

For no food did I find reliable research showing a phase-specific nutritional requirement. What exists is general nutrition (for example, higher iron needs for people who menstruate, which apply all month) and some traditional or theoretical associations that have no clinical support. USDA nutrient composition alone is never treated as evidence for a phase.

## Next steps

1. An independent, documented method for deciding which foods to feature in which phase (proposed in a separate document for approval).
2. Until that is approved, the existing mappings stay as they are and should be described to users only as suggestions.
3. Anything about the origin of the earlier list is for the owner and, if wanted, a qualified adviser.
